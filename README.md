# TextureKit-Addon
TextureKit lets you quickly swap vanilla Minecraft textures with any other Minecraft texture directly inside Blender, without manually replacing texture files.

TextureKit is a Blender addon designed to speed up the workflow of Minecraft artists and animators by making texture swapping and material customization much easier.
You can replace Minecraft's vanilla textures with other Minecraft textures directly inside Blender and customize important shader properties without manually editing materials in the Shader Editor.


Installing TextureKit

Download the latest .zip file from the Releases section below and install it directly into Blender.
In Blender, go to:

Edit → Preferences → Add-ons → Install


Select the downloaded TextureKit-x.x.x.zip file and enable the TextureKit addon.
Note: Keep the downloaded file as a .zip. Do not extract it before installing.

How to Use TextureKit
After installing TextureKit, open your Minecraft model in Blender and find the TextureKit panel.
Choose the Minecraft texture or texture source you want to use and click Swap Textures to quickly replace the existing textures.
TextureKit also supports PBR Texture Swapping, allowing you to add Normal Maps and other supported PBR textures with just one click.

Pixel Perfect
Enable Pixel Perfect to prevent Minecraft textures from appearing blurry.

This keeps the textures sharp and preserves the original pixel-art look of Minecraft.


Custom Block Settings
TextureKit allows you to customize material properties directly from the side panel.

You can adjust settings such as:
Roughness, Metallic, Subsurface Scattering, Anisotropic, Emission and more.
You can apply your settings to Selected materials or All materials at once.

Features
Fast Minecraft Texture Swapping
PBR Texture Swap
One-Click Normal Map Setup
Pixel Perfect Texture Filtering
Custom Material & Shader Settings
Apply Settings to Selected or All Materials
TextureKit is made to save time and simplify the Minecraft animation workflow inside Blender.
Requirements
Blender 4.5+
Minecraft textures or your own Minecraft resource pack are required for texture swapping.
